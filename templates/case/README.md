# Failure title

## Short answer

Summarize the symptom, cause, and fix in one paragraph. If the cause has not
been proven, label it explicitly as a hypothesis.

## Environment

Record the OS, runtime and dependency versions, execution mode, and relevant
hardware.

## Symptom

Describe only observable behavior.

## Reproduction

1. State the initial conditions.
2. List the exact actions.
3. Record the actual and expected results.

## Root cause

Explain the mechanism and provide evidence.

## Failed approaches

For every attempt, record its outcome and side effects.

## Fix

Explain the smallest effective change and its scope.

## Verification and regression coverage

List automated and manual checks.

## Sources

Prefer official documentation, source code, issues, commits, or merge requests
for the relevant version.
